# ONCE

一度だけ、そっと届ける画像共有。

## 現在の開発状況

- GitHub Pages: 画像選択・プレビュー・共有リンク表示・受信画面のプロトタイプを実装
- Cloudflare Workers: ローカル環境でヘルスチェックと画像アップロードを確認
- R2 / Durable Objects: ローカルバインディングの起動を確認
- 本番Workerへの接続、実際の閲覧、90秒・12時間後の削除検証は未完了

**現在は開発中です。実際のプライベートな画像や機密情報の共有には使用しないでください。**

## 想定アーキテクチャ

- GitHub Pages: Web UI
- Cloudflare Workers: API とアクセス制御
- Cloudflare R2: 非公開画像オブジェクトの保存
- Durable Objects: 一回限りの閲覧状態と期限管理

## セキュリティ方針

- 未開封は送信から12時間で失効
- 初回閲覧開始から90秒で失効
- 閲覧権限の消費はサーバー側で原子的に行う
- 期限切れ時はR2オブジェクトを削除し、APIでも取得を拒否
- ログに画像データ、共有トークン、個人情報を残さない
- スクリーンショットを完全に防止できるとは表示しない
