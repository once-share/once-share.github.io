# ONCE

一度だけ、そっと届ける画像共有。

## 現在の開発状況

- GitHub Pages: 画像選択・プレビュー・共有リンク作成・一回限りの受信画面を実装
- 本番API: `https://once-api.orbit-lab-a.workers.dev` を接続先に設定
- 2026-11-15の本番確認: `/api/health` 成功、画像アップロードと共有URL発行成功、初回閲覧成功、同じリンクの2回目の閲覧拒否を確認
- 未確認: 本番環境での未開封12時間失効と閲覧開始後90秒失効の実時間経過テスト
- 画像表示では右クリック/長押しメニュー・ドラッグ・選択を抑止し、タブが非表示になると受信画像を一時的に隠す。ただし、通常のWebページで保存・スクリーンショット・画面録画・別端末撮影を完全に防ぐことはできない

**まだ時間経過による失効と各端末での動作確認が残っています。機密性の高い画像の共有には使用しないでください。**

## 想定アーキテクチャ

- GitHub Pages: Web UI
- Cloudflare Workers: API とアクセス制御
- Cloudflare R2: 非公開画像オブジェクトの保存
- Durable Objects: 一回限りの閲覧状態と期限管理

## セキュリティ方針

- 未開封は送信から12時間で失効
- 初回閲覧開始から90秒で失効
- 閲覧権限の消費はサーバー側で原子的に行う
- 期限切れ時はR2オブジェクトを削除し、APIでも取得を拒否
- ログに画像データ、共有トークン、個人情報を残さない
- スクリーンショットを完全に防止できるとは表示しない
