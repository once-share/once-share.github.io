# ONCE

一度だけ見られる画像共有サービス。

## 開発状況

現在はフロントエンドの初期プロトタイプです。画像アップロード、閲覧トークン、期限切れ削除などのバックエンド機能は未実装です。実際の画像を送信できるサービスとして公開しないでください。

## 想定アーキテクチャ

- GitHub Pages: Web UI
- Cloudflare Workers: API と認可
- Cloudflare R2: 暗号化された画像オブジェクトの保存
- Durable Objects: 一回限りの閲覧状態と期限管理

## セキュリティ方針

- 未開封は送信から12時間で失効
- 初回閲覧開始から90秒で失効
- 閲覧権限の消費はサーバー側で原子的に行う
- 期限切れ時はR2オブジェクトを削除し、APIでも取得を拒否
- ログに画像データ、共有トークン、個人情報を残さない
- スクリーンショットを完全に防止できるとは表示しない

## 開発メモ

削除保証やバックアップ保持期間は、Cloudflare側の実際のストレージ・バックアップ仕様を確認してからユーザー向けに説明すること。
